Nextgen Components manual

Version 0.74.1. Detailed guidance for every public Blazor and Flutter Web component. This documents the implemented API, not full third-party feature parity.

Start with Getting started and Code examples. See data models and formulas for shared model contracts and verification for tested behavior.

Each page includes a live appearance preview with Blazor / Flutter Web switching, followed by the exact source examples, API tables and integration rules. Open the installed NextgenComponents workspace to use the galleries and offline previews. Flutter snippets belong inside a State class with the Material and Nextgen imports; the getting-started page supplies the full application shell.
