NextgenComponents

NextgenComponents is a collection of UI components for Blazor and Flutter Web, with a shared visual language, light and dark themes, and practical examples.

Build consistent interfaces

The current release includes 47 controls on each web platform, covering forms, navigation, data workspaces, visualization and document tools. The component guides describe supported behavior and limitations individually.

  • Forms and input: text boxes, selectors, dates, validation and structured forms.
  • Data workspaces: grids, tree lists, pivot tables and spreadsheets.
  • Navigation: menus, drawers, tabs, steppers and wizards.
  • Visualization: charts, gauges, diagrams and maps.
  • Documents: rich-text editing and PDF viewing.
  • Interaction: dialogs, notifications, tooltips and prompt interfaces.

Try before integrating

Open a component manual to try its live preview. Change values, interact with controls and compare the result with the accompanying code examples. Preview changes use demonstration data and remain separate from your own application.

Download the developer workspace

The Linux, macOS and Windows packages include the interactive galleries, offline manuals and ready-to-connect NuGet and Flutter SDK packages. The included demonstrations run with their bundled runtime. Developing your own application requires the appropriate .NET or Flutter SDK.

Start with Getting started, then browse Code examples or open the Component manual.

Themes and configuration

Use the documented design tokens and supported component parameters to configure density, colors, sizing and behavior. The light and dark themes use the same component contracts. Check each manual for accessibility, keyboard support and integration details.
