Nextgen Remote

Nextgen Remote connects a viewing device to a desktop shared by its owner. Use the desktop app on Linux, macOS or Windows, or open the browser viewer.

What you can do

  • View the host screen through an encrypted session.
  • Request keyboard and mouse control. The host approves and can revoke it.
  • Transfer files and exchange text clipboard content when control is granted.
  • Adjust image quality, frame rate and scale for your connection.

Start here

Read Installation, then Start a remote session. See Permissions and troubleshooting.

Current release

The current release provides Linux x64, macOS Apple Silicon and Windows x64 packages. Desktop capture has been tested on all three platforms. System audio, multiple monitors and full input behavior can depend on the OS and device; do not assume every configuration is verified. This release does not provide access before OS sign-in or a shared address book. Automatic updates require a one-time computer authorization through your website account and MFA; see the installation guide.
